# Day 10 - Statistical Analysis

## Objective

Test whether the observed relationships between dividends and
stock returns are statistically meaningful.

## Statistical Methods

- Pearson correlation
- P-value analysis
- Simple linear regression
- R-squared
- Statistical significance testing

## Relationships Tested

1. Dividend Yield vs Annual Stock Return
2. Dividend Yield vs Total Return
3. Dividend Growth vs Annual Stock Return
4. Dividend Consistency vs Average Stock Return

## Significance Level

A 5% significance level was used.

p < 0.05 indicates statistical significance under the
corresponding test.

## Important Interpretation

Statistical significance does not prove causation.

A non-significant result does not prove that no relationship exists.
It means that this sample and this statistical test do not provide
sufficient evidence of a relationship.

## Regression Model

Annual Stock Return =
Intercept + Slope × Dividend Yield
