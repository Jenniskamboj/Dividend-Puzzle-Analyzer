# Day 4 - Real Financial Data Collection

## Objective

Collect real historical market and dividend data using Python.

## Data Source

Initial market and dividend data is collected using the yfinance Python library.

## First Company

Apple Inc. (AAPL)

## Period

2015-2025

## Data Collected

- Historical stock prices
- Year-end stock price
- Dividend payments
- Annual dividend per share
- Dividend yield

## Calculated Variable

Dividend Yield:

Dividend Yield = Dividend Per Share / Year-End Stock Price × 100

## Output

AAPL_market_dividend_data.csv
