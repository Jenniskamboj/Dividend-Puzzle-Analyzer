# Day 9 - Dividend Consistency, Risk and Return Analysis

## Objective

Investigate whether dividend consistency is associated with
stock performance and risk.

## Analysis Performed

- Dividend consistency calculation
- Dividend growth volatility
- Stock return volatility
- Positive annual return percentage
- Average stock return
- Average dividend yield
- Risk-return analysis
- Dividend yield vs stock return analysis
- Dividend consistency vs stock return analysis

## Important Variables

### Dividend Consistency

Percentage of available year-to-year observations in which
dividend per share increased.

### Stock Return Volatility

Standard deviation of annual stock returns.

### Positive Return Percentage

Percentage of available years with a positive annual stock return.

## Research Questions

1. Do companies with more consistent dividend increases have
   better average stock returns?

2. Do companies with higher dividend yields have higher stock returns?

3. Is higher return associated with higher stock-return volatility?

4. Are consistent dividend policies associated with more stable
   investment outcomes?

## Important Finding

The analysis is exploratory. Correlation does not prove causation.

The current dataset contains dividend-paying companies, so this
analysis does not yet compare dividend-paying companies against
non-dividend-paying companies.
