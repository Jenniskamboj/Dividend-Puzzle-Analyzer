# Day 5 - Automated Financial Data Collection

## Objective

Automate the collection of historical market and dividend data for all selected companies.

## Companies

- Apple (AAPL)
- Microsoft (MSFT)
- Coca-Cola (KO)
- PepsiCo (PEP)
- Johnson & Johnson (JNJ)
- Procter & Gamble (PG)
- McDonald's (MCD)
- Walmart (WMT)
- Exxon Mobil (XOM)
- Verizon (VZ)

## Period

2015-2025

## Data Collected

- Year
- Year-end stock price
- Annual dividend per share
- Dividend yield
- Company
- Ticker

## Automation

Python and yfinance were used to collect the data automatically instead of manually entering each company's data.

## Output

all_companies_market_dividend_data.csv

## Data Quality Checks

- Number of companies checked
- Years checked
- Number of rows checked
- Missing values checked
