# Day 24 – Bird-in-Hand Theory Analysis

## Objective

The objective of Day 24 is to examine whether dividend characteristics are associated with total return and return volatility, providing empirical evidence related to Bird-in-Hand Theory.

## Bird-in-Hand Theory

Bird-in-Hand Theory suggests that investors may prefer certain current dividend income over uncertain future capital gains.

## Variables Used

* Dividend Yield
* Dividend Growth
* Dividend Consistency
* Total Return
* Return Volatility

## Results

| Relationship                              | Correlation |
| ----------------------------------------- | ----------: |
| Dividend Yield vs Total Return            |     -0.4089 |
| Dividend Yield vs Return Volatility       |     -0.3027 |
| Dividend Consistency vs Total Return      |         NaN |
| Dividend Consistency vs Return Volatility |         NaN |
| Dividend Growth vs Total Return           |      0.1139 |
| Dividend Growth vs Return Volatility      |      0.1365 |

## Interpretation

Dividend Yield showed a moderate negative relationship with Total Return (-0.4089).

Dividend Yield also showed a moderate negative relationship with Return Volatility (-0.3027). This suggests that, within the current dataset, companies with higher dividend yields tend to be associated with somewhat lower return volatility.

Dividend Growth showed very weak positive relationships with Total Return (0.1139) and Return Volatility (0.1365).

Dividend Consistency produced NaN correlations because the available data did not contain sufficient variation to calculate a meaningful correlation.

## Conclusion

The results provide mixed and limited empirical support for Bird-in-Hand Theory.

The negative relationship between Dividend Yield and Return Volatility is consistent with the idea that dividend-paying companies may provide relatively stable returns. However, the negative relationship between Dividend Yield and Total Return does not directly support the expectation that investors preferring current dividends necessarily receive higher total returns.

Therefore, Bird-in-Hand Theory cannot be considered strongly supported based on these correlations alone.

Correlation represents association and does not establish causation. The results will be compared with the other Dividend Puzzle theories before identifying the theory with the strongest empirical support.
