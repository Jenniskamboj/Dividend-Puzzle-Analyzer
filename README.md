# Dividend Puzzle Analyzer

## Project Overview

Dividend Puzzle Analyzer is a data-driven financial analysis project that investigates why investors often value dividend-paying companies despite traditional finance theory suggesting that dividend policy should not fundamentally affect firm value under ideal market conditions.

The project combines financial data analytics, statistical analysis, machine learning, and full-stack development to study the Dividend Puzzle.

## Problem Statement

Investors consistently value dividend-paying companies higher, even though traditional finance theory suggests they should not. This long-standing contradiction is known as the Dividend Puzzle.

This project aims to use real-world financial data and machine learning to investigate the factors associated with dividend policies and investor preferences.

## Objectives

- Collect financial and market data
- Analyze dividend-paying companies
- Calculate important financial ratios
- Study relationships between dividends and company performance
- Compare major dividend theories
- Apply statistical analysis
- Apply machine learning techniques
- Build an interactive web dashboard
- Present data-driven conclusions

## Major Theories

1. Dividend Irrelevance Theory
2. Bird-in-the-Hand Theory
3. Tax Preference Theory
4. Signaling Theory
